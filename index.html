Homer Family Assistant

Homer is a private, self-hosted assistant for a small household. It helps authorized household members organize their schedules and coordinate shared plans.

Google Calendar connection

With account-holder permission, Homer can read calendar details and view, create, update, or delete events on calendars accessible to that account. Google controls the permissions each account grants.

The current Google connection requests Calendar access only. It does not request access to Gmail messages or Google Drive files.

Private household access

This site provides information about the assistant and its data practices. It does not offer public registration, access to the assistant, or access to household calendars.
